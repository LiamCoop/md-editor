This project is a nextJS app to allow users to collaborate on Markdown documents using automerge.
It uses Next-auth to authenticate with Azure Active Directory, users can collaborate and leave comments, reply to one another on here.
They should be able to collaborate across multiple documents, we should track comments and cursor positioning.


### Automerge
The core technology we are using is automerge, here is a map of the docs: https://automerge.org/llms.txt
You can use this to navigate to relevant sections.
